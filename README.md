# Tech Challenge I - Saúde da Mulher - Analisando dados para predição do diagnóstico de SOP(Síndrome do Ovário Policístico)

### A Base de dados utilizada, foi sugerida no documento do Tech Challenge e está disponível aqui: https://www.kaggle.com/datasets/prasoonkottarathil/polycystic-ovary-syndrome-pcos. além do diretório 'dataset' desse repositório.

### Preparação do Ambiente de execução

#### 1 - Criação do Ambiente virtual
Para facilitar a execução cria na raiz do projeto um ambiente virtual para a execução do projeto utilizando

```bash
python -m venv .venv
```
#### 2 - Ativando o Ambiente virtual
Para ativar o ambiente virtual execute na pasta onde o ambiente virtual foi criado

```bash
source .venv/bin/activate
```

#### 3 - Instalando as depenências no Ambiente virtual
```bash
pip install -r requirements.txt
```

#### 4 - Executando o Jupyter notebook Localmente
```bash
jupyter notebook main.ipynb
```
